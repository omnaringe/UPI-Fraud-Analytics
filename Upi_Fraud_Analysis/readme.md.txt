UPI Fraud Analytics

📊 Project Overview

This project focuses on analyzing UPI transaction data to identify
fraud patterns, trends, and key risk factors.

The project follows an end-to-end data analytics workflow:

Raw Data → Python EDA → SQL Analysis → Power BI → DAX → Insights

🎯 Objectives

- Analyze fraudulent transaction patterns
- Calculate overall fraud rate
- Identify high-risk transaction categories
- Analyze fraud by bank and merchant category
- Study monthly fraud trends
- Analyze the relationship between risk score and fraud
- Understand the impact of failed transaction attempts

🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI
- DAX
- Data Visualization

🔍 Exploratory Data Analysis

Python was used for:

- Data cleaning
- Missing-value analysis
- Data exploration
- Distribution analysis
- Fraud pattern identification
- Trend analysis

🗄️ SQL Analysis

SQL was used to:

- Query transaction data
- Calculate fraud metrics
- Group transactions by different dimensions
- Identify high-risk categories
- Generate analytical insights

📊 Power BI Dashboard

The final dashboard provides insights into:

- Total Transactions
- Fraud Transactions
- Fraud Rate
- Total Transaction Value
- Legitimate Transactions
- Fraud by Risk Level
- Fraud by Bank
- Fraud by Merchant Category
- Monthly Fraud Trends
- Fraud Rate by Failed Attempts
- Fraud Rate by Risk Score

💡 Key Insights

The dashboard helps identify patterns in fraudulent transactions across different risk factors and transaction categories.
